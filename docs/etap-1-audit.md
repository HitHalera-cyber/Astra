# Этап 1. Аудит NASA CEA

Дата: 03.11.2026. Полная версия отчёта: https://claude.ai/artifact/7XVb5etcdgqhb2qZ8T3wcj

## Итог

- Ядро: NASA CEA 3.3.4 (https://github.com/nasa/cea, коммит `2f79a64`), полная
  реимплементация классической CEA (RP-1311) на Fortran 2008, лицензия Apache 2.0.
- Интеграция: официальный пакет `cea` 3.3.4 с PyPI (Cython → C API → Fortran).
  Для Windows x64 есть готовые колёса для Python 3.11–3.13 с DLL ядра, `cea.exe`
  и базами `thermo.lib`, `trans.lib`. Компиляция Fortran не требуется.
- Результаты Python-привязки совпадают с эталонными выводами NASA
  (`test/main_interface/reference_output`) на задачах RP-1311 №8 (равновесное
  течение) и №12 (замороженное течение) до 4–6 значащих цифр.

## Вычислительные модули ядра

| Модуль | Назначение |
|---|---|
| `equilibrium.f90` | Минимизация энергии Гиббса, фазовое равновесие, производные |
| `rocket.f90` | Камера (IAC/FAC), критическое сечение, сопло; равновесное и замороженное течение |
| `mixture.f90` | Смеси, O/F, φ, r, свойства смеси |

| `transport.f90` | Вязкость, теплопроводность, Pr |

| `input.f90`, `main.f90` | Классический формат `.inp` → `.out` |

## Режимы

TP, HP, SP, TV, UV, SV; Rocket IAC и FAC (списки Pк/P, дозвуковых и сверхзвуковых
ε, точка замораживания состава); Shock; Detonation.

## Особенности интерфейса ядра, важные для Astra

1. Заданные H, U, S передаются низкоуровневому решателю в виде h/R, u/R, s/R
   (h в Дж/кг, s в Дж/(кг·К), R = 8314,51 Дж/(кмоль·К)).
2. Высокоуровневая функция `cea.eq_solve` в версии 3.3.4 передаёт энтальпию в Дж/кг
   без деления на R, и задача HP не сходится (проверено: H2(L)/O2(L), Kм = 5,55157,
   53,3172 бар → `CEA_NOT_CONVERGED`, T = 15 К). Astra её не использует и работает
   через `EqSolver` / `RocketSolver`.
3. Порядок точек Rocket IAC: камера, критическое сечение, затем Pк/P, дозвуковые ε,
   сверхзвуковые ε. FAC: вход в камеру, «бесконечная» камера, конец камеры,
   критическое сечение, далее так же. Индекс замораживания `n_frz` — номер точки.
4. `Isp` ядра — скорость истечения, то есть удельный импульс при Pн = Pа;
   `Isp_vacuum` — в пустоте. При заданном Pн:
   Iуд(Pн) = Iуд.п − Pн·ε·C*/Pк (проверено: при Pн = Pа совпадает с `Isp`).
5. Несходимость не скрывается: `converged = False`, код ошибки, предупреждение.

## Соответствие обозначений

| Astra | Ядро | Примечание |
|---|---|---|
| k | `gamma_s` | показатель изоэнтропы, символ γ не используется |
| μ | `MW` / `M` | газовая фаза / с учётом конденсата |
| Kм | `of_ratio` | |
| α | — | α = Kм / Kм⁰, Kм⁰ = O/F при φ = 1 по валентностям ядра |
| i | `enthalpy` | удельная абсолютная энтальпия |
| H | — | полная энтальпия i + W²/2 (подтверждено заказчиком) |
| C*, M, ε, Kт | `c_star`, `Mach`, `ae_at`, `coefficient_of_thrust` | |

## Ограничения модели

Одномерное идеальное течение без трения и тепловых потерь, идеальный газ,
конденсат без отставания; замороженное течение с фиксацией состава в одной точке;
отрыв потока при перерасширении не моделируется; ядро использует глобальное
состояние, поэтому пакетные расчёты распараллеливаются по процессам.
